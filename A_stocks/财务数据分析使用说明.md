# 财务数据分析使用说明

## 功能概述

通过API补充完整财务数据，统计沪深300中**最赚钱的公司**和**被低估的公司**。

## 回答您的问题

### Q: 公司的总市值通过市盈率和什么计算？

**答案：**
- **总市值 = 市盈率 × 净利润**
- 或者：**总市值 = 股价 × 总股本**

在我们的分析中：
- 从Excel表中直接获取：总市值、市盈率（动态）
- 通过API补充：净利润、营业收入、ROE、每股收益等
- 如果净利润缺失，会通过公式反推：**净利润 = 总市值 / 市盈率**

## 使用方法

### 1. 运行脚本

```bash
python analyze_profitable_undervalued.py
```

### 2. 选择数据获取方式

脚本会询问：
- **选项1**：完整获取所有股票财务数据（推荐，约90秒）
- **选项2**：仅获取前50只股票（快速测试）
- **选项3**：跳过API获取，仅使用现有数据进行统计

### 3. 查看分析结果

脚本会自动输出：
- **最赚钱的公司 TOP 20**：按净利润排序
- **被低估的公司 TOP 20**：综合低PE、低PB、盈利能力强

### 4. 导出结果（可选）

可以选择导出到CSV文件，文件名为：`分析结果_YYYYMMDD_HHMMSS.csv`

## 分析指标说明

### 最赚钱的公司（盈利能力）

**主要指标：**
- **净利润**：公司实际赚的钱（单位：元，显示时转换为亿元）
- **ROE（净资产收益率）**：衡量盈利效率
- **净利润率**：净利润/营业收入，反映盈利质量

**排序方式：** 按净利润从高到低

### 被低估的公司（估值分析）

**主要指标：**
- **市盈率（PE）**：总市值/净利润，越低越好（但需注意行业差异）
- **市净率（PB）**：总市值/净资产，越低越好
- **ROE**：盈利能力，ROE高的公司更有价值
- **综合得分**：综合考虑PE、PB和盈利能力

**评分公式：**
```
综合得分 = (1/PE × 60% + 1/PB × 40%) + 盈利加分
盈利加分：有净利润 +0.2，ROE>10% 再+0.2
```

**排序方式：** 按综合得分从高到低

## 数据来源

1. **基础数据**：从 `沪深300.xls` 读取
   - 股票代码、名称、行业
   - 现价、总市值、市盈率、市净率
   - 涨幅等

2. **财务数据**：通过 akshare API 获取
   - 净利润、营业收入
   - ROE、每股收益
   - 总股本、净资产等

## 注意事项

1. **API频率限制**：akshare可能有频率限制，脚本默认延迟0.3秒/只股票
2. **数据完整性**：部分股票可能无法获取财务数据，会跳过
3. **估值参考**：PE、PB的合理区间因行业而异，建议结合行业对比
4. **数据时效性**：财务数据来自最新季报/年报，可能存在延迟

## 技术实现

- **Python库**：
  - `pandas`：数据处理
  - `akshare`：股票财务数据API
  - `csv`：结果导出

- **核心方法**：
  - `get_financial_data()`：获取单只股票财务数据
  - `batch_get_financial_data()`：批量获取
  - `calculate_metrics()`：计算完整指标
  - `find_most_profitable()`：找最赚钱的公司
  - `find_undervalued()`：找被低估的公司
