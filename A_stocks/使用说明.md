# 股票数据管理系统使用说明

## 功能概述

`manage_stocks.py` 是一个股票数据管理系统，提供数据导入、查询、统计、导出功能，支持三张表的数据管理。

### 支持的数据库表

1. **csi300_stocks** - 沪深300成分股表
2. **orders_intraday** - 委托表
3. **positions_intraday** - 持仓表

### 功能模块

#### 【沪深300成分股查询】（选项 1-7）
- 按股票代码查询
- 按股票名称模糊查询
- 按行业查询
- 查询涨幅榜（前N名）
- 查询跌幅榜（前N名）
- 按价格范围查询
- 查询所有记录

#### 【沪深300成分股统计】（选项 8-10）
- 统计总记录数
- 统计行业分布
- 统计涨跌幅信息

#### 【委托查询】（选项 11-13）
- 查询所有委托记录（按时间倒序）
- 按证券代码查询委托
- 按委托状态查询

#### 【委托统计】（选项 14）
- 委托统计信息：总委托数、已成交、已撤单、买入/卖出委托数量、成交总金额

#### 【持仓查询】（选项 15-18）
- 查询所有持仓（按盈亏率排序）
- 按证券代码查询持仓
- 查询盈利持仓
- 查询亏损持仓

#### 【持仓统计】（选项 19）
- 持仓统计信息：总持仓数、总盈亏、平均盈亏率、总市值、盈利/亏损持仓数量

#### 【导入功能】（选项 20-21）
- 导入委托和持仓数据（从 `当日委托.xls` 和 `资金持仓.xls`）
- 导入/更新沪深300成分股数据（从 `沪深300.xls`）

## 数据导出

所有查询和统计结果都可以导出为CSV文件：

- **默认文件名**：自动生成带时间戳的文件名，如 `export_20250128_143022.csv`
- **编码格式**：UTF-8 with BOM，可在Excel中正确打开
- **导出时机**：查询结果后询问是否导出

## 文件说明

### 核心文件

- **manage_stocks.py** - 主程序（查询、统计、导入、导出）
- **import_orders_positions.py** - 委托和持仓数据导入脚本
- **db_config.py** - 数据库配置文件
- **test_db_connection.py** - 数据库连接测试脚本

### 数据源文件

- **沪深300.xls** - 沪深300成分股数据（制表符分隔，GBK编码）
- **当日委托.xls** - 委托数据（制表符分隔，GBK编码）
- **资金持仓.xls** - 持仓数据（制表符分隔，GBK编码）

### 配置说明

数据库配置在 `db_config.py` 中：

```python
DB_CONFIG = {
    'host': '127.0.0.1',
    'port': 3306,
    'user': 'root',
    'password': 'guox123123',
    'database': 'stocks',
    'charset': 'utf8mb4'
}
```

## 注意事项

1. **数据更新**：导入沪深300数据会清空表并重建，原有数据会被删除
2. **委托和持仓**：导入时会清空旧数据并重建表
3. **数据库连接**：确保MySQL服务正在运行
4. **文件格式**：数据源文件必须是制表符分隔的文本文件，使用GBK或GB2312编码
5. **CSV导出**：导出的CSV文件使用UTF-8-BOM编码，Excel可直接打开

## 常见问题

### Q: 查询结果为空？
A: 请先导入数据。使用选项20导入委托和持仓数据，或使用选项21导入沪深300数据。

### Q: 导入失败？
A: 请检查：
1. 数据源文件是否存在
2. 文件编码是否正确（GBK）
3. 数据库连接是否正常
4. 是否有足够的数据库权限

### Q: 导出文件乱码？
A: 导出的CSV使用UTF-8-BOM编码，如果Excel显示乱码：
1. 打开Excel
2. 选择"数据" → "从文本/CSV导入"
3. 选择UTF-8编码

### Q: 连接数据库失败？
A: 请检查 `db_config.py` 中的配置：
- MySQL服务是否正在运行
- 主机地址、端口是否正确
- 用户名和密码是否正确
- 数据库是否存在

## 技术实现

- **数据库**：MySQL 8.4.6
- **Python版本**：Python 3.x
- **主要依赖**：
  - pymysql（数据库连接）
  - pandas（数据处理）
  - csv（CSV导出）
- **数据表**：
  - csi300_stocks（沪深300成分股表）
  - orders_intraday（委托表）
  - positions_intraday（持仓表）

## 快速开始

1. **配置数据库**：编辑 `db_config.py` 设置数据库连接信息
2. **测试连接**：运行 `python test_db_connection.py`
3. **导入数据**：运行 `python manage_stocks.py`，选择选项20或21
4. **查询数据**：选择相应的查询选项
5. **导出数据**：查询后选择导出到CSV文件
