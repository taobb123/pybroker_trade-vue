## ❓ 需要您确认的关键决策

### 1. 数据来源问题 ⚠️ **最重要**

**问题**：历史股票数据从哪里获取？

**选项A**：从现有数据库获取
- 当前数据库有历史OHLC数据表吗？
- 如果有，表名和字段结构是什么？

**选项B**：使用数据API获取
- 使用tushare、akshare等API获取
- 需要安装额外依赖和配置API密钥

**选项C**：混合方案
- 数据库中有数据就用数据库，没有就从API获取

**建议**：先确认数据库是否有历史数据，如果没有，我建议先用模拟数据开发核心功能，再集成真实数据源。

### 2. 数据库配置

**问题**：如何管理数据库配置？

**选项A**：直接引用父级`../db_config.py`
```python
import sys
sys.path.append('..')

```

**选项B**：在项目内创建独立配置
- `config/db_config.py`，可以继承或覆盖父级配置

**建议**：选项A更简单，项目内创建配置文件更独立。

**问题**：默认均线周期设置？

**选项A**：固定参数（5, 20）

**选项B**：可配置参数
- 通过配置文件或构造函数传入

**建议**：选项B，更加灵活。

### 4. 回测精度

**问题**：回测需要考虑哪些因素？

**选项A**：基础回测
- 只考虑手续费（commission）
- 假设按收盘价成交

**选项B**：精细回测
- 手续费
- 滑点（slippage）
- 买卖价差
- 成交量限制

**建议**：Phase 1先用选项A，Phase 2再加入精细回测。
