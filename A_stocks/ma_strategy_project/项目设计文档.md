# 均线策略项目设计文档

## 一、项目目标

实现一个基于双均线策略的量化交易系统，重点在于：
1. **理解整个流程**：数据获取 → 策略生成信号 → 回测验证 → 实盘执行
2. **可复用架构**：模块化设计，便于扩展和维护
3. **易于使用**：清晰的接口和文档

## 二、架构设计

### 2.1 模块划分

```
┌─────────────┐
│   主程序    │  main.py - 流程编排
└──────┬──────┘
       │
       ├──► 数据层 (data/)
       │    └── DataFetcher - 从数据库/API获取数据
       │
       ├──► 策略层 (strategies/)
       │    ├── BaseStrategy - 策略基类（抽象接口）
       │    └── MovingAverageStrategy - 双均线策略实现
       │
       ├──► 回测层 (backtest/)
       │    ├── BacktestEngine - 回测引擎
       │    └── PerformanceAnalyzer - 性能分析
       │
       ├──► 执行层 (execution/)
       │    ├── StrategyExecutor - 策略执行器
       │    └── OrderManager - 订单管理
       │
       ├──► 风控层 (risk/)
       │    └── RiskManager - 风险管理（仓位、止损等）
       │
       └──► 工具层 (utils/)
            ├── Logger - 日志记录
            └── Visualizer - 结果可视化
```

### 2.2 数据流设计

```
历史数据 ──► DataFetcher ──► DataFrame
                                    │
                                    ├──► Strategy.generate_signals() ──► 交易信号
                                    │
                                    └──► BacktestEngine.run() ──► 回测结果
```

### 2.3 核心类设计

#### DataFetcher（数据获取）
```python
class DataFetcher:
    def fetch_stock_data(code, start_date, end_date) -> pd.DataFrame
    # 返回：date, open, high, low, close, volume
```

#### BaseStrategy（策略基类）
```python
class BaseStrategy:
    def generate_signals(data) -> pd.DataFrame
    # 返回数据包含signal列：1=买入, -1=卖出, 0=持有
```

#### MovingAverageStrategy（均线策略）
```python
class MovingAverageStrategy(BaseStrategy):
    def __init__(short_window=5, long_window=20)
    def generate_signals(data) -> pd.DataFrame
```

#### BacktestEngine（回测引擎）
```python
class BacktestEngine:
    def __init__(strategy)
    def run(data, initial_capital, commission=0.001) -> dict
    # 返回回测结果字典，包含收益率、持仓等
```

#### RiskManager（风险管理）
```python
class RiskManager:
    def check_position_size(position, total_capital) -> bool
    def check_stop_loss(current_price, entry_price) -> bool
    def check_take_profit(current_price, entry_price) -> bool
```

## 三、关键设计决策

### 3.1 数据格式标准
所有策略接收和返回的DataFrame格式：
- `date`: 日期（datetime或字符串）
- `open`, `high`, `low`, `close`: OHLC数据
- `volume`: 成交量
- `signal`: 交易信号（1/-1/0）
- `positions`: 持仓变化（1=买入, -1=卖出）

### 3.2 策略接口设计
所有策略必须实现：
- `generate_signals(data)` 方法
- 返回包含signal列的DataFrame
- 信号格式统一：1=买入, -1=卖出, 0=持有

### 3.3 回测参数
- `initial_capital`: 初始资金（默认100000）
- `commission`: 手续费率（默认0.001，即0.1%）
- `slippage`: 滑点（可选）

### 3.4 配置管理
- 数据库配置：引用父级`db_config.py`
- 策略参数：通过配置文件或构造函数传入
- 日志配置：统一日志格式和路径
