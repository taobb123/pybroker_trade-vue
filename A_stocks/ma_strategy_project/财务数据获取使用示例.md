# 财务数据获取模块使用示例

## 模块概述

`FinancialDataFetcher` 是财务数据获取核心模块，用于从API获取股票财务数据，支持事件驱动策略（财报策略）的实现。

## 快速开始

### 基本使用

```python
from data.financial_fetcher import FinancialDataFetcher

# 使用上下文管理器（推荐）
with FinancialDataFetcher() as fetcher:
    # 获取单只股票的财务数据
    financial_data = fetcher.get_financial_data('000001')
    
    if financial_data:
        print(f"净利润: {financial_data['net_profit']:,.0f} 元")
        print(f"营业收入: {financial_data['revenue']:,.0f} 元")
        print(f"ROE: {financial_data['roe']}%")
```

### 支持的股票代码格式

模块支持多种股票代码格式：

```python
with FinancialDataFetcher() as fetcher:
    # 以下格式都可以正常使用
    codes = [
        '000001',      # 纯数字（推荐）
        'SZ000001',    # 深交所带前缀
        'SH600519',    # 上交所带前缀
    ]
    
    for code in codes:
        data = fetcher.get_financial_data(code)
        print(f"{code}: {data['code'] if data else '获取失败'}")
```

## 获取的财务指标

模块会自动标准化以下财务指标：

### 盈利能力指标
- `net_profit`: 净利润（元）
- `revenue`: 营业收入（元）
- `roe`: 净资产收益率（%）
- `roa`: 总资产收益率（%）
- `eps`: 每股收益（元）
- `profit_margin`: 净利润率（%）- 自动计算

### 财务结构指标
- `total_assets`: 总资产（元）
- `total_liabilities`: 总负债（元）
- `net_assets`: 净资产（元）
- `asset_liability_ratio`: 资产负债率（%）- 自动计算
- `bps`: 每股净资产（元）

### 现金流指标
- `operating_cashflow`: 经营现金流（元）
- `free_cashflow`: 自由现金流（元）

### 股本信息
- `total_shares`: 总股本（万股）
- `circulating_shares`: 流通股本（万股）

## 缓存机制

模块内置内存缓存，避免重复请求：

```python
with FinancialDataFetcher() as fetcher:
    # 第一次获取（调用API）
    import time
    start = time.time()
    data1 = fetcher.get_financial_data('000001')
    time1 = time.time() - start
    
    # 第二次获取（从缓存读取）
    start = time.time()
    data2 = fetcher.get_financial_data('000001')
    time2 = time.time() - start
    
    print(f"首次获取耗时: {time1:.2f} 秒")
    print(f"缓存读取耗时: {time2:.4f} 秒")
    print(f"缓存加速: {time1/time2:.0f}x")
```

### 清空缓存

```python
with FinancialDataFetcher() as fetcher:
    fetcher.clear_cache()  # 清空内存缓存
```

## 错误处理

模块会自动处理各种错误情况：

```python
with FinancialDataFetcher() as fetcher:
    # 无效代码返回None
    invalid_codes = ['', None, '999999', 'INVALID']
    for code in invalid_codes:
        data = fetcher.get_financial_data(code)
        if data is None:
            print(f"{code}: 无法获取数据")
```

## 完整示例

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
财务数据获取完整示例
"""

from data.financial_fetcher import FinancialDataFetcher

def analyze_stock(code):
    """分析单只股票的财务数据"""
    with FinancialDataFetcher() as fetcher:
        financial_data = fetcher.get_financial_data(code)
        
        if not financial_data:
            print(f"{code}: 无法获取财务数据")
            return
        
        print(f"\n{'='*70}")
        print(f"股票代码: {financial_data['code']}")
        print(f"{'='*70}")
        
        # 盈利能力分析
        print("\n【盈利能力】")
        if financial_data['net_profit']:
            print(f"  净利润: {financial_data['net_profit']/1e8:.2f} 亿元")
        if financial_data['revenue']:
            print(f"  营业收入: {financial_data['revenue']/1e8:.2f} 亿元")
        if financial_data['roe']:
            print(f"  ROE: {financial_data['roe']:.2f}%")
        if financial_data['eps']:
            print(f"  每股收益: {financial_data['eps']:.2f} 元")
        
        # 财务结构分析
        print("\n【财务结构】")
        if financial_data['total_assets']:
            print(f"  总资产: {financial_data['total_assets']/1e8:.2f} 亿元")
        if financial_data['asset_liability_ratio']:
            print(f"  资产负债率: {financial_data['asset_liability_ratio']:.2f}%")
        
        # 数据完整性
        total_fields = len(financial_data)
        non_null_fields = len([v for v in financial_data.values() if v is not None])
        print(f"\n【数据完整性】")
        print(f"  已获取指标: {non_null_fields}/{total_fields}")
        print(f"  完整度: {non_null_fields/total_fields*100:.1f}%")

if __name__ == '__main__':
    # 测试多只股票
    test_codes = ['000001', '600519', '601318']
    
    for code in test_codes:
        analyze_stock(code)
```

## 集成到策略中

### 在事件驱动策略中使用

```python
from data.financial_fetcher import FinancialDataFetcher
from strategies.base import BaseStrategy

class EarningsReportStrategy(BaseStrategy):
    """财报策略示例"""
    
    def __init__(self):
        super().__init__()
        self.fetcher = FinancialDataFetcher()
    
    def generate_signal(self, code: str, date: str):
        """基于财务数据生成交易信号"""
        # 获取财务数据
        financial_data = self.fetcher.get_financial_data(code)
        
        if not financial_data:
            return None
        
        # 策略逻辑：ROE > 15% 且净利润增长
        if financial_data.get('roe', 0) > 15:
            return {
                'action': 'buy',
                'reason': f"ROE={financial_data['roe']:.2f}%",
                'strength': 'strong' if financial_data.get('roe', 0) > 20 else 'medium'
            }
        
        return None
```

## 注意事项

1. **API频率限制**: akshare可能有频率限制，批量获取时建议增加延迟
2. **数据完整性**: 不同股票的财务数据完整度可能不同
3. **数据时效性**: 财务数据来自最新报告期，可能存在延迟
4. **缓存有效期**: 内存缓存在程序运行期间有效，重启后需重新获取
