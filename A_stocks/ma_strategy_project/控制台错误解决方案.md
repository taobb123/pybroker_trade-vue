# 控制台错误解决方案

## 🔴 常见控制台错误

### 错误1: "message channel closed before a response was received"

**错误信息**:
```
Uncaught (in promise) Error: A listener indicated an asynchronous response by returning true, but the message channel closed before a response was received.
```

**原因分析**:
1. **浏览器扩展干扰**: 广告拦截器、开发者工具扩展等可能拦截iframe通信
2. **Streamlit iframe通信**: Streamlit的`components.html`在iframe中加载内容，某些扩展会干扰通信
3. **异步操作超时**: Plotly或mpld3的JavaScript在iframe中执行时，与父窗口通信超时

**影响**:
- ⚠️ **通常不影响图表显示**: 这些错误主要是警告，不会阻止图表渲染
- ⚠️ **可能影响交互功能**: 某些交互功能（如工具栏按钮）可能无法正常工作
- ✅ **图表数据正常**: 图表的核心功能（显示数据）通常不受影响

**解决方案**:

#### 方案1: 已添加的错误处理（推荐）
代码中已添加错误处理脚本，会自动捕获并忽略这些错误：
```javascript
// 自动捕获并忽略message channel错误
window.addEventListener('error', function(e) {
    if (e.message && e.message.includes('message channel')) {
        e.preventDefault();
        return false;
    }
});
```

#### 方案2: 禁用浏览器扩展
1. 打开Chrome开发者工具（F12）
2. 进入"Console"标签
3. 点击右上角的设置图标
4. 勾选"Hide network messages"（隐藏网络消息）
5. 或者暂时禁用广告拦截器等扩展

#### 方案3: 使用无痕模式
在无痕模式下测试，排除扩展干扰：
- Chrome: `Ctrl+Shift+N`
- Edge: `Ctrl+Shift+P`

### 错误2: 多个警告信息

**常见警告**:
- `mpld3.v0.5.11.js` 相关警告
- `index.CAj-7vWz.js` 相关警告
- `about:srcdoc` 相关警告

**原因**:
- 这些通常是JavaScript库的兼容性警告
- 不影响核心功能

**解决方案**:
- 这些警告可以忽略
- 如果影响使用，可以在控制台设置中过滤警告消息

## 📊 诊断步骤

### 步骤1: 检查图表是否实际显示
1. 忽略控制台错误（如果图表正常显示）
2. 检查图表数据是否正确
3. 测试交互功能（缩放、平移、工具提示）

### 步骤2: 如果图表不显示
1. **检查HTML生成**:
   ```python
   # 在代码中添加
   print(f"HTML长度: {len(chart_result)}")
   print(f"HTML前500字符: {chart_result[:500]}")
   ```

2. **检查数据有效性**:
   ```python
   from utils.data_validator import validate_data_for_plot
   is_valid = validate_data_for_plot(data, plot_type="mr")
   print(f"数据验证: {is_valid}")
   ```

3. **检查日志输出**:
   - 查看Python控制台的日志
   - 查找 `[plot_mean_reversion_signals]` 或 `[_plot_mr_with_plotly]` 相关日志

### 步骤3: 浏览器控制台检查
1. 打开开发者工具（F12）
2. 进入"Console"标签
3. 查看是否有红色错误（非警告）
4. 检查"Network"标签，确认Plotly.js是否成功加载
