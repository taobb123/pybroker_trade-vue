# 财务数据与回测系统集成说明

## 已完成功能

### ✅ 1. 财务指标计算模块 (`utils/financial_metrics.py`)

**功能**：
- `calculate_valuation_metrics()`: 计算市盈率(PE)和市净率(PB)
- `calculate_comprehensive_score()`: 计算综合得分
- `get_financial_display_data()`: 获取完整的财务显示数据

**综合得分公式**：
```
综合得分 = (1/PE × 60% + 1/PB × 40%) + 盈利加分
盈利加分：有净利润 +0.2，ROE>10% 再+0.2
```

## 使用方法

### 在Streamlit应用中使用

```python

```

### 在Python脚本中使用

```python
from utils.visualization import plot_price_ma_signals
from strategies.moving_average import MovingAverageStrategy

# 生成信号数据
strategy = MovingAverageStrategy(short_window=5, long_window=20)
sig_df = strategy.generate_signals(data)

# 绘制图表（带财务指标）
fig_path = plot_price_ma_signals(
    sig_df, 
    stock_code='000001',  # 传入股票代码
    interactive=False
)
```

## 技术实现

### 布局方案（方案B）

- **位置**：图表内部左侧，Y轴位置
- **排列方式**：竖直排列，与Y轴平行
- **显示方式**：使用matplotlib的`text()`函数
- **样式**：标题加粗，数值普通，综合得分加粗并标红

### 数据获取流程

1. **回测时**：传入股票代码 `stock_code`
2. **图表绘制时**：
   - 调用 `get_financial_display_data()` 获取财务数据
   - 使用最新收盘价计算总市值（如果需要）
   - 计算PE、PB和综合得分
3. **显示**：在图表左侧竖直排列显示

### PE/PB计算逻辑

```python
# PE = 总市值 / 净利润
if total_market_value and net_profit > 0:
    pe_ratio = total_market_value / net_profit

# PB = 总市值 / 净资产
if total_market_value and net_assets > 0:
    pb_ratio = total_market_value / net_assets

# 总市值计算（如果未提供）
if current_price and total_shares:
    total_market_value = current_price * total_shares * 10000  # 万股转股
```

## 注意事项

1. **数据可用性**：如果财务数据获取失败，图表仍会正常显示，只是不显示财务指标
2. **性能**：财务数据会被缓存，避免重复API调用
3. **错误处理**：所有财务数据获取错误都会被静默处理，不影响主图表显示
4. **编码问题**：Windows环境下可能存在编码警告，但不影响功能
