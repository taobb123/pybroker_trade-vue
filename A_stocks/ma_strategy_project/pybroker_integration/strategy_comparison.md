# 策略对比分析：rotation_trade.py vs tr_rota.py

## 关键差异总结

虽然两个文件都使用相同的轮动逻辑（基于20日ROC排名），但存在以下**关键差异**导致回测收益不同：

### 1. **买入条件不同** ⚠️ **最重要差异**

#### rotation_trade.py (第56行)
```python
if ctx.symbol in top_symbols:  # top_symbols 是前5名
    ctx.buy_shares = ctx.calc_target_shares(target_size)
```
- **买入范围**：前5名中的任意股票都可能被买入
- **可能同时持有**：如果前5名中有多只股票，可能同时买入多只（受 `max_long_positions=2` 限制）
- **选股标准较宽松**

#### tr_rota.py (第104行)
```python
top_k_symbols = top_symbols[:max_positions]  # 只取前2名
if ctx.symbol in top_k_symbols:  # 只在前2名中买入
    ctx.buy_shares = ctx.calc_target_shares(target_size)
```
- **买入范围**：只买入前2名（最优秀的股票）
- **选股标准更严格**：只选择ROC最高的2只股票

**影响**：`tr_rota.py` 只买入最优秀的股票，理论上应该表现更好，但可能错过一些机会。

---

### 2. **风险管理机制** ⚠️ **重要差异**

#### rotation_trade.py
```python
# 没有设置任何止损或止盈
```
- **无止盈**：即使盈利10%也不会自动卖出
- **无移动止损**：即使从高点回撤20%也不会自动卖出
- **完全依赖轮动逻辑**：只有股票跌出前5名才卖出

#### tr_rota.py (第108-112行)
```python
ctx.stop_profit_pct = take_profit_pct      # 10% 止盈
ctx.stop_trailing_pct = trail_pct          # 20% 移动止损
```
- **有止盈**：价格上涨10%时自动卖出，锁定利润
- **有移动止损**：从最高价回撤20%时自动卖出，控制风险
- **双重保护**：既有轮动逻辑，也有风险管理

**影响**：
- **止盈**：可能提前锁定利润，但也可能错过更大的涨幅
- **移动止损**：可能减少亏损，但也可能在震荡市中过早卖出

---

### 3. **卖出条件** ✅ **相同**

两个文件都使用相同的卖出逻辑：
- 如果股票不在前5名中，则卖出

---

## 收益差异的决定因素

### 主要因素（按重要性排序）：

1. **买入选股标准** (最重要)
   - `rotation_trade.py`：可能买入前5名中的任意股票
   - `tr_rota.py`：只买入前2名
   - **影响**：选股质量直接影响收益

2. **止盈机制** (重要)
   - `rotation_trade.py`：无止盈，可能持有到更高收益或回吐利润
   - `tr_rota.py`：10%止盈，提前锁定利润但可能错过更大涨幅
   - **影响**：在上涨行情中，`rotation_trade.py` 可能收益更高；在震荡行情中，`tr_rota.py` 可能更稳定

3. **移动止损机制** (重要)
   - `rotation_trade.py`：无移动止损，可能承受更大回撤
   - `tr_rota.py`：20%移动止损，控制回撤但可能过早卖出
   - **影响**：在下跌行情中，`tr_rota.py` 可能亏损更小；在震荡行情中，可能交易更频繁

---

## 预期收益差异分析

### 场景1：强势上涨行情
- **rotation_trade.py** 可能收益更高
  - 无止盈，可以持有到更高价格
  - 可能买入更多股票（前5名中的任意股票）
  
- **tr_rota.py** 可能收益较低
  - 10%止盈会提前卖出，错过后续涨幅
  - 只买入前2名，可能错过一些机会

### 场景2：震荡行情
- **tr_rota.py** 可能表现更好
  - 止盈和移动止损可以锁定利润、控制风险
  - 只买入最优秀的股票，质量更高
  
- **rotation_trade.py** 可能表现较差
  - 无止盈，利润可能回吐
  - 无移动止损，可能承受更大回撤

### 场景3：下跌行情
- **tr_rota.py** 可能亏损更小
  - 移动止损可以及时止损
  - 只买入最优秀的股票，相对更抗跌
  
- **rotation_trade.py** 可能亏损更大
  - 无移动止损，可能承受更大回撤
  - 可能买入质量稍差的股票（前5名中的后3名）

## 建议

如果要让两个策略收益更接近，可以：

1. **统一买入条件**：
   - 将 `rotation_trade.py` 的买入条件改为只买入前2名
   - 或将 `tr_rota.py` 的买入条件改为买入前5名

2. **统一风险管理**：
   - 在 `rotation_trade.py` 中添加止盈和移动止损
   - 或移除 `tr_rota.py` 中的止盈和移动止损

3. **测试不同参数组合**：
   - 测试不同的止盈比例（5%, 10%, 15%）
   - 测试不同的移动止损比例（15%, 20%, 25%）
   - 测试不同的买入范围（前2名 vs 前5名）
