## A. 产品经理发言（需求复述 + 约束）

### 1. 背景判断

现状：网站仍偏「业余量化工具 / 工作流执行台」——有跑策略、配额、支付壳，但**用户为什么情愿付费**尚未被产品语言讲清。

下一阶段目标：从「能跑工具」升级为「愿为决策纪律付费」——引入巴菲特可传播理念，按用户心理设计**降低情绪交易、自动约束出手时机**的产品体验；做出**最小价值 MVP** 验证付费意愿。

**明确忽略**：价值建设文档中一切依赖大模型的能力（AI 综合分、AI 研究报告、AI 机会扫描文案等）。用**规则化评分 + 既有策略/信号产物**替代。

### 2. 目标（解决谁的什么问题）

| 项 | 内容 |
|----|------|
| 用户 | 普通投资者：易受涨跌情绪驱动，频繁出手、难坚持等待 |
| 问题 | 缺「只打好球」的外部约束；行情软件给信息，不给**不交易的许可** |
| 成功 | 用户打开产品时问的是「今天有没有好球？」，愿意为**少做错、只在高概率出手**付费 |

### 3. 核心价值（一句话）

> **FreeAlpha：帮助普通投资者减少情绪化错误交易，只在规则判定的「好球」出现时出手；用能力圈、安全边际、等待好球约束决策。**

三根理念柱（必须体现在 UI 文案与流程，不可只写在介绍页）：

| 理念 | 产品落点（无 AI） |
|------|-------------------|
| 能力圈 | 只展示平台已覆盖的策略/形态/池内机会，不假装覆盖全市场 |
| 安全边际 | 展示「当前价 vs 理想买入区 / 评分门槛」，未进入则标为等待 |
| 等待好球 | **观察池 + 默认不推荐买**；无好球时明确「今日无好球」 |

心理设计（服务意识）：

- 用户怕错过 → 产品用「观察池 / 目标区」承接焦虑，而不是天天推买
- 用户怕做错 → 产品用「可解释的多维评分 + 风险一句」降低盲目跟风
- 用户需要被允许不交易 → 空状态「今日无好球」是功能，不是缺陷

### 4. 范围

#### 做（价值 MVP 最小切片）

1. **机会雷达首页（P0）**  
   入口从「因子/策略列表」改为「今天有没有好球？」  
   三块：市场环境（简）→ 好机会列表（好球）→ 空则「今日无好球」。

2. **规则化好球评分卡（P0）**  
   借鉴 Seeking Alpha Quant Rating 形态，**不用 AI**：  
   技术趋势 / 基本面（若有）/ 资金（若有）/ 估值或安全边际（可用既有模型或占位规则）→ **综合分 + 是否好球**。  
   用户结论句固定口径：「现在是不是好球？是 / 否 / 等待」。

3. **观察池 + 目标买入区（P0，巴菲特最关键）**  
   加入观察 → 设定/展示理想买入区 → 未进入则「等待」；禁止做成每日荐股墙。

4. **从好球 → 既有工作流/报告（P1）**  
   好球卡片可跳转：跑相关工作流 / 看已有报告产物（复用现有能力，不新堆策略）。

5. **付费门控对齐价值（P1）**  
   Free：有限好球条数 / 观察池容量；Pro：完整雷达 + 更大观察池 + 报告导出（沿用既有套餐数字，文案改成价值语言）。

#### 暂不做

| 不做 | 原因 |
|------|------|
| AI 报告 / AI 综合 / 大模型对话 | 未接入；避免虚假承诺 |
| 预测涨停 / 明日牛股 / 跟单 / 高频信号 | 损害可信度（价值建设文档红线） |
| 模仿传统行情软件全功能 | 偏离决策纪律定位 |
| 新增大量策略/因子 | 本轮验证「决策流程产品化」，非技术堆料 |
| 完整行业热力图 / 宏大 Dashboard | 可二期；MVP 只保留雷达三块 |

### 5. 关键路径

```
登录（可延用现闭环）
  → 机会雷达：「今天有没有好球？」
  → 有：评分卡（是好球 / 等待）→ 加入观察池 或 打开研究/跑工作流
  → 无：明确「今日无好球」+ 引导去观察池看等待中标的
  → 触达 Free 限额 → 升级 CTA（文案：解锁完整好球与观察纪律）
  → Pro：导出报告 / 更大池（既有闭环）
```

### 6. 硬约束

1. **无 AI 文案**：界面不得出现「AI 评分 / AI 研报」等未实现能力；可用「规则评分 / 策略信号 / 模型分」。  
2. **空仓合法**：无好球日必须可展示，禁止用假机会填满首页。  
3. **不荐每日必买**：默认姿态是等待；买入区未达则不可暗示「现在就该买」。  
4. **复用闭环**：用户身份 / 配额 / 支付 / 漏斗继续有效；本轮主要改**价值层 IA 与首页路径**，不推翻商业闭环。  
5. **可解释**：评分卡至少展示分项，禁止纯黑盒「综合建议买入」。  
6. **合规口径**：工具辅助决策，非投资建议（沿用既有免责，文案需出现在雷达页）。

### 7. 验收标准

| # | 标准 |
|---|------|
| V1 | 未登录/已登录均可进入雷达首页；首屏主问题是「今天有没有好球？」而非工作流列表 |
| V2 | 至少 1 条好球卡片展示：分项分 + 是否好球 + 一句上涨/等待逻辑 + 风险一句（可用 mock 规则，但结构真实） |
| V3 | 无数据或无达标机会时，展示「今日无好球」，且可进入观察池 |
| V4 | 观察池：可添加、可看到目标买入区 vs 现价、状态为等待/进入区 |
| V5 | 从好球可跳到既有工作流或报告（至少一条通路） |
| V6 | 界面无「AI」能力暗示；付费 CTA 文案强调「完整好球与观察纪律」 |
| V7 | 不破坏既有：登录、跑工作流、配额、支付、导出主路径仍可走通 |
