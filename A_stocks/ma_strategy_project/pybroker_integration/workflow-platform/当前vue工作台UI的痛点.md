# 一、最大问题：页面纵向结构仍然像“任务详情页”

现在结构：

```
标题
 |
按钮
 |
输入
 |
输出链接
 |
Data Table
```

用户体验：

> 我要运行一个策略，然后看结果。

但是视觉：

> 我打开了一篇策略说明文档。

建议改成：

## 工作流三段式

```
┌──────────────────────────────┐
│ 策略名称   状态   最近运行时间 │
└──────────────────────────────┘


┌──────────┬──────────┬──────────┐
│ 输入参数 │ 执行状态 │ 输出结果 │
│          │          │          │
└──────────┴──────────┴──────────┘


┌──────────────────────────────┐
│ 股票结果表                   │
└──────────────────────────────┘
```

不要上下堆。

# 三、“高级/输入”不应该放这里

现在：

```
高级 / 输入 ▼
```

位置比较尴尬。

原因：

你的用户不是配置系统，而是在研究策略。

建议：

改成右侧抽屉：

点击：

```
⚙ 参数
```

打开：

```
──────────────
运行参数

均线:
MA5

周期:
20

股票池:
沪深A股

保存结果:
√

[保存]
──────────────
```

类似 Shadcn Sheet。

