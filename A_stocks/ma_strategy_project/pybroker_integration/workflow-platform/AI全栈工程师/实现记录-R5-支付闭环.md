## 交付

| 项 | 路径 |
|----|------|
| 支付 API | `payment_api.py`（挂载于 `workflow_server`） |
| 前端 API | `src/api/payment.ts` |
| 套餐支付 Sheet | `BillingPlansPage.vue` |
| 权益生效 | `billing.checkoutPro` → `auth.setPlan` + 订单 |

## 闭环形状

```
选择 Pro → 选渠道（微信/支付宝/演示）
  → POST /api/payment/create（pending）
  → POST /api/payment/simulate-pay/{id}（等同回调成功）
  → 本地 plan=pro + expireAt + 订单 paid
```

真机替换点：将 `simulate-pay` 换为微信/支付宝下单二维码 + `/api/payment/callback/{channel}` 验签入账。
