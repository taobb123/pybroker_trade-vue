# 实现记录 · 凯利仓位（半凯利 + 20% 上限）

## 产品确认

- 统计口径 **A**：按分组共用 p/b（非个股各自）  
- **半凯利** + 单票上限 **20%**  
- 产物以 **CSV / 日志** 为主（不依赖东财自选写入仓位数字）  

## 适用范围

| 步骤 | 分组 | p/b 来源变体 |
|------|------|-------------|
| `fetch_pattern_entry` | 量能 / M加 / M减 | `A_L` / `M+_L` / `M-_L` ← `market_neutral/output/latest` |
| `vp_combo_23_long_compare` | 23M减 | `M-_L` ← `market_neutral/output/combo23_latest` |

不含：估值因子、Q。

## 公式

- \(f^* = p - (1-p)/b\)，其中 p=月胜率，b=平均盈利月 / |平均亏损月|（来自仅多头净值月收益）  
- 建议仓位 = `min(20%, 0.5 * f*)`
