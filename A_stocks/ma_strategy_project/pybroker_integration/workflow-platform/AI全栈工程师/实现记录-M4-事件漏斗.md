# 实现记录 · M4 事件埋点与漏斗

> 纪要：`../产品经理/协作纪要/005-MVP闭环规则-基于1.2.md`  
> 规则：`MVP闭环规则-v1.md` §3.6 / §4.4

## 交付

| 项 | 路径 |
|----|------|
| 表 | `events`（`db.py`） |
| 服务 | `events_service.py` |
| API | `POST /api/events/track` · `GET /api/events/funnel` |
| 服务端埋点 | `run_strategy`（consume）· `payment_success`（paid） |
| 前端埋点 | `page_view` / `click_upgrade` / `export_report` |
| 展示 | `/usage` 转化漏斗卡片 |

## 五类事件

| 事件 | 触发 |
|------|------|
| page_view | 进入 `/workflows` `/billing/plans` `/reports` |
| run_strategy | 配额 consume 成功 |
| export_report | 报告复制/下载成功 |
| click_upgrade | 打开 Pro 支付 Sheet |
| payment_success | 订单变为 paid |
