## 交付

| 项 | 说明 |
|----|------|
| `WorkflowStep.tier` | `basic` / `advanced` |
| `resolveStepTier` / `isAdvancedStep` | `businessRules.ts` |
| `assertCanRun(step)` | Free 拦截 advanced |
| UI | 「高级 · Pro」徽标；按钮「需 Pro」+ 升级 |

## 判定优先级

1. YAML/API `tier` 字段  
2. `ADVANCED_STEP_IDS` 白名单  
3. `highlight === 'core'` → advanced  
4. 否则 basic  

## 验收

- [x] Free 无法跑 advanced（如市场温度计 / 形态建仓）  
- [x] Pro 可跑  
- [x] basic（如 ROC20）Free 仍可跑（受日配额约束）
