# Notebooks 目录

本目录存放探索性数据分析（EDA）、原型设计、临时性分析或概念验证的 Jupyter Notebooks。

## 使用场景

- **探索性数据分析（EDA）**: 数据探索、可视化、统计分析
- **原型设计**: 策略原型、算法验证
- **临时性分析**: 临时性的数据分析和实验
- **概念验证**: 新想法、新技术的概念验证

## 注意事项

⚠️ **重要**: 这些 Notebooks 通常不用于生产部署

## 文件命名规范

建议使用以下命名规范：
- `{date}_{topic}_{version}.ipynb` - 例如: `20241129_macd_rsi_analysis_v1.ipynb`
- `{author}_{topic}.ipynb` - 例如: `alice_volume_analysis.ipynb`

## 最佳实践

1. 定期清理过期的 Notebooks
2. 重要的分析结果应整理到 `docs/` 目录
3. 可复用的代码应提取到 `src/` 目录
4. 在 Notebook 中记录分析目的和结论
