# 源代码目录

本目录存放核心源代码。代码应按模块或功能划分。

## 目录结构

### modules/ - 功能模块
具体的功能模块，例如：
- 数据处理模块
- 特征工程模块
- 模型训练模块
- 回测引擎模块
- 交易执行模块
- 风险管理模块

### strategies/ - 交易策略
存放不同的交易策略实现：
- 移动平均策略
- 均值回归策略
- 轮动策略
- 机器学习策略
- 等等

### utils/ - 工具函数
存放通用的辅助函数和工具：
- 数据验证工具
- 可视化工具
- 日志工具
- 工具类函数

## 代码组织原则

1. **模块化**: 每个模块应有明确的职责
2. **可复用**: 代码应设计为可复用的组件
3. **文档化**: 重要的函数和类应有文档字符串
4. **测试**: 每个模块应有对应的单元测试
