# 文档目录

本目录存放项目文档、研究报告、API 文档、设计规范等。

## 文档类型

### 项目文档
- `README.md` - 项目总体说明
- `INSTALLATION.md` - 安装指南
- `CONTRIBUTING.md` - 贡献指南

### 研究报告
- 策略研究报告
- 回测分析报告
- 性能评估报告

### API 文档
- API 接口说明
- 函数/类文档
- 使用示例

### 设计规范
- 架构设计文档
- 代码规范
- 数据格式规范

## 文档维护

1. 保持文档与代码同步更新
2. 使用 Markdown 格式编写文档
3. 重要决策应记录在文档中
4. 定期审查和更新文档
