# 文档目录

本目录存放项目文档、研究报告、API 文档、设计规范等。

## 文档类型

### 项目文档
- `README.md` - 项目总体说明
- `INSTALLATION.md` - 安装指南
- `CONTRIBUTING.md` - 贡献指南

### 研究报告
- 策略研究报告
- 回测分析报告
- 性能评估报告

### API 文档
- API 接口说明
- 函数/类文档
- 使用示例

### 设计规范
- 架构设计文档
- 代码规范
- 数据格式规范
- `常用工作步骤数学公式对照表.md` — 常用工作流的符号、类型（门闩 / 分数 / 标签 / 假设）与代码位置
- `系统参数初始状态.md` — 2026-09-26 冻结的常数，调参后按此回退
- `块A第一期参数搜索.md` — 观察池 10 日收益的参数搜索口径；报告不写回线上常数
- `袖子均值方差第一期.md` — W4、W6、M+、Q 的样本外加权比较；不改线上仓位
- `文档第15节袖子实验.md` — 用现有回测截面把 W4、W6、M+、Q、G 收成时间序列，比较等权、按收益排序、均值—方差
- `问题三_W23对W46.md` — 固定等权，比较 W2∪W3 与 W4∪W6；最后一段不成立则命题不标成成立
- `系统能力两层检验.md` — 选股层与组合构造层分开打分；构造工具含均值—方差、收益排序、半凯利、温度
- `P0选股Alpha检验.md` — 超额、状态未来收益、IC 衰减、温度条件收益；不改线上规则

## 文档维护

1. 保持文档与代码同步更新
2. 使用 Markdown 格式编写文档
3. 重要决策应记录在文档中
4. 定期审查和更新文档
