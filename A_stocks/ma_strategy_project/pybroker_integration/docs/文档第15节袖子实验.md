# 文档第 15 节袖子实验

脚本：`doc15_sleeve_experiment.py`。

把现有市场中性回测的截面（`market_neutral/output/latest/factor_snapshot.csv`）收成五条日收益：

- \(W_4\)、\(W_6\)：调仓日 combo 4、combo 6 等权，持有到下次调仓。
- \(M^+\)、\(Q\)：与该回测相同，因子前 10% 做多。\(M^+\) 按周，\(Q\) 按月。
- \(G\)：公告日不晚于调仓日的营收同比与净利润同比，池内前 13 名，按月。四层稳健质量分的现成拉取不带公告日，不套用到这段历史上。

样本外比较等权、按收益排序、均值—方差。等权用来回答选股有没有赚钱；后两种相对等权的增量用来回答组合构造有没有多赚钱。累计收益不为正，不叫赚钱。

运行：

```text
python doc15_sleeve_experiment.py
```

产物在 `output/doc15_sleeves/report.md`。脚本不修改线上配置。
