# 问题三：W2∪W3 对 W4∪W6

脚本：`h0_w23_vs_w46.py`。

第 15 节要回答的是信号组本身：等权多头下，\(W_2\cup W_3\) 的年化是否不高于 \(W_4\cup W_6\)。上一张等权 / 按收益排序 / 均值—方差的表回答的是权重怎么分，不能当作这个命题的检验。

本实验固定等权。同一批股票用初始 θ 做 Phase1 分类，滚动 6 个交易日。日差 \(D_t=R_t(W_4\cup W_6)-R_t(W_2\cup W_3)\)。最后约 20% 交易日只看一次。最后一段年化仍然是 \(W_4\cup W_6\) 更高，且日差均值大于 0，才把命题标成这段样本支持。

运行：

```text
python h0_w23_vs_w46.py
```

产物在 `output/h0_w23_w46/report.md`。脚本不修改线上配置。
