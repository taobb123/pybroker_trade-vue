## 回退办法

1. 按上表把源码常量改回初始值。
2. 工作流 `args` 改回上节。
3. 若温度阶梯已被校准 JSON 换掉，而希望回到本表阶梯：恢复 `DEFAULT_POSITION_BUCKETS`，并不要让校准文件继续覆盖。
4. 观察池 CSV、股票列表、运行历史不是参数。回退参数不会自动还原那些文件。
