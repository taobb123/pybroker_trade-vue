# 七、Python实现逻辑（简化）

```python
factors = {
    "momentum": momentum_score,
    "value": value_score,
    "quality": quality_score,
    "volume": volume_score
}


# 计算因子近期表现

factor_return={}

for factor in factors:

    factor_return[factor]=(
        backtest_factor(factor)
    )


# 根据表现分配权重

weights = softmax(
    factor_return
)


# 综合评分

alpha=0

for factor in factors:

    alpha += (
        weights[factor]
        *
        factors[factor]
    )


stocks_rank = alpha.sort_values(
    ascending=False
)
```

你说的《战胜一切市场的人》（原名 *A Man for All Markets*）作者是爱德华·O·索普（Edward O. Thorp），他是量化投资的先驱之一。这本书里提到的并不是一个简单的“预测明天股价”的公式，而是一套**基于概率、估值和风险调整的价格预测体系**。书中核心思想包括“科学预测股票价格”“价格锚定”和凯利公式等。([book.douban.com][1])

索普真正使用的核心公式，可以拆成几个层次：

---

## 1. 股票合理价格公式（索普式价格预测核心）

索普认为股票价格长期由未来现金流决定：

[
P=\frac{D_1}{r-g}
]

其中：

* (P)：股票合理价格
* (D_1)：下一年的预期股息
* (r)：投资者要求收益率（折现率）
* (g)：长期增长率

这实际上就是简化版的股利折现模型（DDM）。

例如：

某股票：

* 当前每股盈利：5元
* 分红率：40%
* 股息：

[
D=5\times40%=2元
]

假设：

* 长期增长率 (g=5%)
* 要求收益率 (r=10%)

那么：

[
P=\frac{2}{0.1-0.05}
]

[
P=40元
]

如果市场价格：

* 20元 → 低估
* 40元 → 合理
* 60元 → 高估

# 2. 索普更重要的公式：概率优势公式

索普真正厉害的地方不是预测价格，而是判断：

> 当前价格是否低于真实概率价值。

他的投资思想类似：

[
EV=p\times G-(1-p)\times L
]

其中：

* EV：期望收益
* p：上涨概率
* G：上涨收益空间
* L：下跌损失

例如：

某股票：

上涨概率：

[
p=60%
]

上涨：

+30%

下跌：

-10%

那么：

[
EV=0.6\times30%-0.4\times10%
]

[
EV=18%-4%
]

[
EV=14%
]

长期来看具有正收益优势。

这比单纯预测：

“明天涨还是跌”

更接近量化投资本质。

# 3. 凯利公式：决定仓位

索普最著名的是凯利公式：

[
f^*=\frac{bp-q}{b}
]

其中：

* (f^*)：最佳仓位比例
* (b)：盈利赔率
* (p)：成功概率
* (q=1-p)

例如：

你判断：

上涨概率：

60%

上涨赚：

30%

亏损：

10%

赔率：

[
b=\frac{30}{10}=3
]

那么：

[
f=\frac{3\times0.6-0.4}{3}
]

[
f=46.7%
]

理论最佳仓位约47%。

实际投资通常使用：

[
0.25f^*
]

即：

四分之一凯利。

因为市场估计概率存在误差。
