## 量化实现约定（首期）

工作流链路：

`fetch_a_low_ma5` → `fetch_vp_six_combo` → **`fetch_pattern_entry`**

### 上游配合（六组合）

- 主表 `vp_six_combo_scan.csv` 增加突破锚点：`platform_level`、`breakout_high`、`breakout_close`、`breakout_vol`、`breakout_vol_ratio`。
- 按 `watch_combo_ids`（默认 `[4, 6]`）滚动合并观察表 `vp_combo_watch_{id}.csv`（最多 6 个交易日、同票只留最新 `signal_date`），并同步 symbols txt；主表 `vp_six_combo_scan.csv` 仍为当日截面覆盖。
- 跑 `fetch_pattern_entry` 时，仅将 `state=作废` 的代码从对应观察池剔除；次日六组合可重新进池。

### 建仓步骤（形态）

- 脚本：`fetch_pattern_entry.py`
- 输入：默认读 `vp_combo_watch_4.csv`（上涨放量突破）；可用 symbols / pool 覆盖。
- 形态注册表可扩展；已实现：
  - `breakout_pullback_rebreak` ↔ `combo_id=4`
  - `volume_dump_reversal` ↔ `combo_id=6`

### 严格主路径（唯一 `entry=True`）

1. **Watch**：六组合命中「上涨放量突破」→ 记录平台与突破高/量，**不建仓**。
2. **Confirming**：突破后 2~5 日内缩量回踩，低点不破平台（兼看 MA10），记 `pullback_ok`。
3. **Entry**：回踩确认后，收盘突破 `breakout_high` 且放量 → `entry=True`。
4. **Invalid**：收盘跌破平台；爆量滞涨；回踩/再突破超时。

辅助因子（MA5 承接、MACD 红柱、换手递减）只进 `score` / `notes`，**不单独触发建仓**。

输出：`pattern_entry_scan.csv`（`state` 为中文信号特征；另有 `state_code` 英文码）。按 建仓 / 缩量回踩确认 / 观察 / 作废 等分组。

## 量化实现约定（第二种形态：下跌放量）

触发：六组合 `combo_id=6`（下跌放量）→ 导出 `vp_combo_watch_6.csv` / `config/fetch_pattern_entry_symbols_6.txt`。

形态 id：`volume_dump_reversal`

锚点语义：

- `breakout_day` = 恐慌放量日（观察起点，非买点）
- `platform_level` = 上方压力位（突破前平台高）
- `breakout_vol` = 恐慌日成交量（后续缩量参照）

状态机：

| state（中文） | 含义 | 仓位标注 |
|------|------|----------|
| 观察 | 下跌放量当日/尚未止跌 | 0 |
| 止跌缩量候选 | 止跌缩量，加入观察池 | 0 |
| 试仓·放量破压 | 放量突破压力（试仓信号） | `trial_ok` · `position_frac=0.2` |
| 缩量回踩确认 | 缩量回踩不破压力（加仓信号） | `add_ok` · `position_frac=0.6` |
| 建仓 | 再放量创新高（系统建仓） | `entry=True` · `position_frac=1.0` |
| 作废 | 再创新低 / 破压跌回 / 超时 | 清观察 |

严格约定：`entry=True` 仅在最终「再放量创新高」（且 MACD 红柱健康、MA20 走平或上拐）。  
无量反弹贴近压力不加试仓。

`fetch_pattern_entry.py` 默认 `--combo-id 0` 同时扫描形态1+2。

跑完后自动推送东财自选分组「量能」（需 `MX_APIKEY` 或 `config/mx_apikey.txt`）：

- **待选** ← `止跌缩量候选` / `试仓·放量破压` / `缩量回踩确认`（仅写 CSV `select_tag`，**不推送**）
- **待选后通过** ← `建仓`（**仅此类推送**自选）

CSV 增加列 `select_tag`；可用 `--skip-mx-push` 关闭推送，`--mx-group` 改分组名。

## 这是我认为最适合你的最终交易模型

结合我们之前关于"底部缩量、底部放量上涨、上涨缩量整理、上涨放量突破、下跌放量"的讨论，我建议把**"下跌放量"细分成三个子阶段**：

> **下跌放量（观察） → 止跌缩量（候选） → 放量反转（建仓）**

这样，**"下跌放量"就不再是买点，而是一个进入观察池的信号**。

对于这张天赐材料的图，我会把它定义为：

* **当前状态：止跌反弹初期（观察池）**
* **不是建仓阶段。**

**我的建仓条件会非常明确：**

1. **放量突破40元附近的平台压力**（最好成交量达到近5日均量的1.5倍以上）。
2. **随后缩量回踩40元不破**，确认压力转为支撑。
3. **再次放量突破回踩后的高点**，同时MACD红柱继续放大、20日均线开始走平或上拐。

满足这三个条件，我才会认为它真正从"下跌放量"过渡到了**"上涨放量突破"**，这也是与你当前量价交易体系最一致、胜率更高的建仓位置。
