你的这套筛选条件可以作为回测的起点，但仅凭这四个条件，不能判断它能否持续跑赢市场。关键不是筛出来的股票历史表现有多好，而是这些条件能否提高未来持有期的成本后超额收益。

结合你截图里的数据，我建议先保留四个指标，但修改它们的筛选逻辑，再通过分组回测决定最终阈值。

## 一、先把你的四个条件改成可检验的假设

| 指标         | 你的假设                      | 建议调整          | 原因               |
| ---------- | ------------------------- | ------------- | ---------------- |
| Beta       | \\(0\leq\beta\leq0.5\\)   | 保留，作为低 Beta 组 | 低市场敏感度不等于高超额收益   |
| 年化 Alpha   | \\(-10\\%<\alpha<40\\%\\) | 暂时不设硬性上限      | 高 Alpha 不等于处于高位  |
| 120日 Alpha | \\(>0\\)                  | 保留            | 但需要确认近期优势是否持续    |
| 超额收益       | \\(>0\\)                  | 保留            | 应扣除成本，并明确基准和计算区间 |

这里最需要修正的是年化 Alpha 的上限。

股票是否处于高位，应由价格位置、涨幅、估值和趋势等指标判断，而不是由 Alpha 是否超过40%判断。 如果一只股票年化 Alpha 为45%，但它的 Alpha 稳定、估值合理、趋势仍然向上，没有必要仅因为超过40%就剔除。

## 二、你的筛选条件还有一个统计问题

从截图来看：

- 舒华体育：Beta 为0.390，年化 Alpha 为45.51%，120日 Alpha 为 -101.34%。
- 大连圣亚：Beta 为0.485，年化 Alpha 为40.06%，120日 Alpha 为64.15%。
- 国芳集团：Beta 为0.432，年化 Alpha 为19.89%，120日 Alpha 为108.85%。

这些数字说明，低 Beta 股票也可能有非常不同的近期表现。

尤其是截图中 \\(R^2\\) 只有0.01～0.02，意味着市场指数对这些股票收益波动的解释能力很弱。此时，单因子模型计算出来的 Alpha 可能混合了行业、规模、成长、动量等其他因素的影响。

此外，120日 Alpha 出现极端值时，需要检查计算公式和年化方式。假如年化 Alpha 使用的是日度回归截距乘以交易日数，而120日 Alpha 使用另一种计算方法，两者就不能直接比较。

## 三、我建议你采用三层筛选

第一层：历史风险与收益过滤

- Beta：0～0.5，建立低风险候选组。
- 历史超额收益：大于0。
- 120日 Alpha：大于0。

作用：剔除部分历史表现较弱的股票，而不是直接预测未来。

第二层：超额收益质量验证

- Alpha 的统计显著性。
- 过去滚动窗口中 Alpha 为正的比例。
- 信息比率 IR。
- 最大回撤和交易成本。

作用：区分偶然跑赢市场和具有持续性的超额收益。

第三层：未来入场时机

- 20日与60日 Alpha 的变化。
- 行业相对强度。
- 量价结构与成交量变化。
- 价格位置和回撤风险。

作用：判断股票现在是否值得买入，而不是仅仅因为历史表现优秀就买入。

## 四、怎样验证它真的能跑赢市场？

不要一开始就把所有指标组合成一个复杂评分。先做下面这组对照实验。

| 策略         | 筛选条件                    |
| ---------- | ----------------------- |
| A：基准组      | 不使用 Alpha/Beta 筛选       |
| B：低 Beta 组 | \\(0\leq\beta\leq0.5\\) |
| C：历史优势组    | B + 年化 Alpha 为正         |
| D：近期优势组    | C + 120日 Alpha 为正       |
| E：质量验证组    | D + Alpha 稳定性、IR 筛选     |

每组使用相同股票池、调仓规则和持有期限，比较：

- 年化超额收益；
- 成本后收益；
- 信息比率；
- 最大回撤；
- 样本外收益；
- 不同市场环境下的表现。

你需要特别防止幸存者偏差、未来数据泄漏和反复调参造成的过拟合。所有筛选指标都只能使用买入时已经公开的数据。

如果 D 组明显优于 A、B、C 组，而且 E 组在样本外仍然保持优势，才能说明这些指标组合可能具有实际价值。

## 五、给你一个可直接执行的初始版本

我会先使用以下规则作为实验条件，而不是直接认定为最终交易策略：

\\[ \begin{aligned} &0\leq\beta\_{250}\leq0.5\\\ &\alpha\_{250}>0\\\ &\alpha\_{120}>0\\\ &ER\_{120,\text{net}}>0 \end{aligned} \\]

其中 \\(ER\_{120,\text{net}}\\) 是过去120个交易日扣除交易成本后的累计超额收益。Alpha 的计算方法需要统一，且必须使用与基准一致的收益频率。

然后增加一个独立的评分，而不是硬性过滤：

\\[ Score=w_1 IR+w_2 S\_{\alpha}+w_3 M\_{\alpha} \\]

其中：

- \\(IR\\)：信息比率。
- \\(S\_{\alpha}\\)：Alpha 稳定性。
- \\(M\_{\alpha}\\)：近期 Alpha 动能。
- \\(w_1,w_2,w_3\\)：通过样本外验证选择的权重。

这样既保留你的低 Beta 思路，又不会因为一个指标的阈值不合适，就把潜在的高 Alpha 股票全部排除。

最终判断标准只有一个：在相同的交易成本和风险约束下，这套规则是否能在未参与调参的样本中，持续获得正的超额收益。 如果做不到，就需要调整假设，而不是继续增加筛选条件。
