CAPM（资本资产定价模型）在复盘中的核心作用，是帮助你回答一个比“这只股票今天为什么涨跌”更重要的问题：

这笔交易赚到的钱，究竟来自市场整体上涨、承担了更高的市场风险，还是来自你真正的选股能力？

结合你正在构建的 A 股量化系统——包括多因子选股、信号组收益排序、动态风险收益模型和持仓评分——CAPM 可以充当一把“收益归因的基准尺”。它不直接告诉你明天买什么，而是帮助你判断过去的盈利究竟从哪里来，以及你的策略是否创造了超出市场风险补偿的收益。

## 一、CAPM 反映了股票赚钱或亏钱的什么底层逻辑？

CAPM 的基本思想是：承担不可分散的市场风险，投资者应当获得相应的预期收益补偿。

其经典公式为：

\\[ E(R_i)=R_f+\beta_i[E(R_m)-R_f] \\]

其中：

- \\(E(R_i)\\)：股票的预期收益率。
- \\(R_f\\)：无风险利率，例如适当期限的国债收益率。
- \\(E(R_m)\\)：市场组合的预期收益率。
- \\(\beta_i\\)：股票对市场整体波动的敏感程度。
- \\(E(R_m)-R_f\\)：市场风险溢价。

这条公式揭示了三种不同的收益来源。

1\. 市场收益：市场整体带来的收益

市场上涨时，即使你没有特别优秀的选股能力，持有市场贝塔较高的股票，也可能赚钱；市场下跌时，也可能跟着亏钱。

2\. 风险暴露：你承担了多少市场风险

β 越高，股票通常对市场波动越敏感。牛市中可能涨得更多，熊市中也可能跌得更深。但高 β 不代表必然高收益。

3\. 超额收益：你的策略是否创造了额外价值

如果扣除市场风险所能解释的收益后，股票仍然表现更好，那么剩余部分就是 CAPM 框架下的异常收益，常用 α 表示。

这里需要区分：CAPM 解释的是预期收益与系统性风险的关系，并不能完整解释每一只股票的实际涨跌。公司业绩、估值变化、行业景气、资金流和偶发事件，都可能造成模型解释不了的收益。

## 二、复盘时如何使用 CAPM：从实际收益中拆出市场贡献和超额收益

将理论转化为复盘工具，关键是使用实际收益建立一个市场模型：

\\[ R\_{i,t}-R\_{f,t} =\alpha_i+\beta_i(R\_{m,t}-R\_{f,t})+\varepsilon\_{i,t} \\]

这是用于历史收益分析的回归形式。这里的 \\(\alpha_i\\) 是估计出来的截距，\\(\varepsilon\_{i,t}\\) 是某个交易日无法被市场模型解释的部分。

它与 CAPM 的均衡理论有区别：CAPM 本身并不承诺每只股票都能获得正 α。实际复盘时，我们用估计的 α 检验策略是否有超额表现。

### 用一个例子理解

假设你买入一只 A 股，持有 20 个交易日，复盘得到以下结果。

股票实际收益

# +8%

同期市场收益

# +5%

股票 β

# 1.2

无风险利率（同期）

# +0.1%

为方便理解，假设这些数据都对应同一持有期，且 β 在该期间保持不变。

市场模型预测收益：

\\[ 0.1\\%+1.2(5\\%-0.1\\%)=5.98\\% \\]

实际收益减去模型预期收益

# +2.02%

这笔交易的含义是：

- 股票赚了 8%，但并不是所有收益都来自你的判断。
- 在这个模型下，大约 5.98% 可以由无风险收益和市场风险暴露解释。
- 剩余的约 2.02% 是实际收益高于模型预期的部分。

注意，这里的 2.02% 只是单次持有期的收益差额，不是经过统计检验的可靠 Alpha。严格来说，应该用多期数据估计 α，并考虑交易成本、估计误差和显著性。

### 复盘的四种典型情形

| 实际表现       | CAPM 复盘结果    | 可能的解释               |
| ---------- | ------------ | ------------------- |
| 股票上涨，α 为正  | 跑赢市场风险基准     | 选股、行业景气或事件等可能带来额外收益 |
| 股票上涨，α 接近零 | 收益基本可由市场风险解释 | 可能只是市场上涨时跟着上涨       |
| 股票下跌，α 为正  | 跌幅小于模型预期     | 可能有相对抗跌能力，但绝对收益仍为负  |
| 股票上涨，α 为负  | 涨幅低于模型预期     | 承担了市场风险，却没有获得相应表现   |

因此，你不能只用“这笔交易赚了还是亏了”评价策略，而应该同时问：

1. 市场本身提供了多少收益？
2. 这只股票承担了多少系统性风险？
3. 扣除模型能够解释的部分后，还剩下多少超额收益？

这也是专业投资绩效评估中，收益测量、收益归因和投资能力评价三个环节的区别。

## 三、β 的底层逻辑：为什么有些股票涨得多、跌得也多？

β 的数学定义是：

\\[ \beta_i=\frac{\operatorname{Cov}(R_i,R_m)} {\operatorname{Var}(R_m)} \\]

它衡量的不是股票自身有多危险，而是股票收益与市场收益共同波动的程度。

| β 值 | 含义         | 市场上涨时的典型表现 | 市场下跌时的典型表现 |
| --- | ---------- | ---------- | ---------- |
| 0.5 | 对市场不太敏感    | 涨幅可能较小     | 跌幅可能较小     |
| 1.0 | 与市场敏感度相近   | 接近市场敏感度    | 接近市场敏感度    |
| 1.5 | 对市场较敏感     | 涨幅可能更大     | 跌幅可能更大     |
| 负值  | 历史上与市场反向波动 | 可能表现相反     | 可能表现相反     |

以上是历史关系的示意，不是未来收益的保证。

从投资逻辑看，股票的风险可以分成两类：

系统性风险：无法靠简单分散持股消除

例如整体流动性收紧、市场风险偏好下降、宏观经济冲击。CAPM 用 β 衡量股票对市场系统性风险的暴露。

非系统性风险：公司或局部事件带来的风险

例如业绩暴雷、核心客户流失、管理层问题。持有足够多相关性较低的股票，可以分散其中一部分。

但分散投资不能保证消除行业风险、流动性风险或极端市场风险。

CAPM 的一个重要启示是：承担更多可分散的公司特有风险，并不意味着投资者理应获得更高的预期收益。

## 四、如何把 CAPM 接入你的 A 股量化系统？

我建议把它放在你现有的系统里，作为收益归因与风险评估层，而不是直接作为选股因子。

第一层：选股信号

营收同比、净利润同比、技术形态、行业强弱

第二层：组合构建

持仓权重、资金分配、风险预算

第三层：CAPM 复盘

市场收益、β、α、残差风险

第四层：策略评价与迭代

判断超额收益是否持续、是否值得承担当前风险

### 1. 先选择正确的市场基准

对于你的 A 股系统，可以考虑：

- 沪深300：衡量偏大盘股票的市场暴露。
- 中证500：衡量偏中盘股票的市场暴露。
- 与策略实际投资范围相匹配的宽基指数：衡量整个策略的相对表现。

如果组合同时持有大盘股、中盘股及小盘成长股，单一指数可能不能充分解释收益。你可以先以一个预先指定的宽基指数作为统一基准，再用其他指数进行稳健性检验。

### 2. 用滚动回归估计 β 和 α

对每只股票或每个信号组，使用历史收益率进行回归：

\\[ R\_{i,t}-R\_{f,t} =\alpha_i+\beta_i(R\_{m,t}-R\_{f,t})+\varepsilon\_{i,t} \\]

可以先尝试使用过去 120 或 250 个交易日的数据估计参数，再每天滚动更新。

需要注意：窗口越短，参数越容易受到噪声影响；窗口越长，参数又可能无法及时反映市场风格变化。可以比较不同窗口的稳定性，而不是预先认定某个窗口最优。

### 3. 建立策略复盘表

| 复盘指标      | 回答的问题               |
| --------- | ------------------- |
| 实际收益      | 最终赚了多少钱？            |
| 基准收益      | 市场整体涨跌多少？           |
| β         | 策略对市场波动有多敏感？        |
| α         | 扣除市场风险暴露后，是否还有超额表现？ |
| \\(R^2\\) | 市场模型解释了历史收益波动的多少？   |
| 残差波动率     | 还有多少收益波动无法被市场模型解释？  |
| 最大回撤      | 最坏阶段的资金损失有多大？       |

其中，\\(R^2\\) 高不代表策略好，只表示模型对历史收益波动的解释程度较高；残差也不等于纯粹的选股能力，它还包含遗漏因子和随机噪声。

## 五、CAPM 能否帮助你实现动态风险收益最大化？

可以提供基础，但单因子 CAPM 不足以解决整个动态规划问题。

你的系统已经有营收增长、利润增长、技术形态和市场强弱等变量。下一步可以将 CAPM 扩展为多因子收益模型：

\\[ R\_{i,t}-R\_{f,t} =\alpha_i+\beta\_{m,i}F\_{m,t} +\beta\_{g,i}F\_{g,t} +\beta\_{v,i}F\_{v,t} +\varepsilon\_{i,t} \\]

其中：

- \\(F_m\\)：市场收益因子。
- \\(F_g\\)：增长或动量因子。
- \\(F_v\\)：价值或估值因子。

这只是示意结构。实际使用时，需要明确每个因子的构造方式，避免重复计量，并使用样本外检验验证其增量解释能力。多因子模型比 CAPM 更适合分析多个系统性收益来源，但同样不能保证预测有效。

你可以按下面的逻辑迭代：

1. 收益归因： 判断当前收益有多少来自市场贝塔。
2. 因子归因： 检查增长、动量等因子能否解释额外收益。
3. 参数更新： 根据滚动样本重新估计 β、α 及其不确定性。
4. 风险预算： 在预期收益、协方差、交易成本和最大回撤约束下优化持仓。
5. 样本外验证： 判断收益提升是否真正持续，而非参数过拟合。

尤其要注意：历史 α 不应直接当成未来预期收益。若要将它用于仓位优化，必须对其进行收缩估计，并评估估计误差，否则优化器可能过度集中于历史表现最好的信号。

我对你当前系统的建议是：先实现 CAPM 收益归因，再考虑用它调整仓位。 这样你就能先分清楚，某个信号组过去赚的钱究竟主要来自市场上涨，还是确实表现出了独立的超额收益能力。只有把这个问题搞清楚，后续的贝叶斯更新、蒙特卡洛模拟和动态风险预算才有可靠的基础。
