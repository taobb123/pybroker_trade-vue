# 常用工作步骤 · 数学公式对照表

落表日期：2026-09-26。行号会随改动漂移，**以函数名 / 配置键为准**。

用途：改阈值、改入池或改回测假设之前，先在本表定位符号。一次只改一行，并按「类型」决定该用成员差还是收益来检验。

本表描述**当前实现**，不新增筛选。`match_exact`、共振分不决定观察池成员。

## 类型

| 类型 | 含义 | 改它之后看什么 |
|---|---|---|
| 定义 | 与代码同义的量 | 实现是否仍等于式子 |
| 门闩 | 决定集合谁进谁出 | 改前改后的成员差，以及其后收益 |
| 分数 | 只排序或展示 | 池子应不变；看次序、Rank IC、前 n 后验 |
| 标签 | 诊断，不进门闩 | 标签分布；成员集应不变 |
| 算子 | 把上游集合变成下游集合 | 输入输出集合 |
| 假设 | 可用未来收益否证 | 固定门闩后的年化 / IC，不同时改池子 |

## 工作流步骤

配置：`config/workflow_runner.yaml`。

| 步骤 | 脚本 | 本表符号 |
|---|---|---|
| 东财概念低位×资金热门扫描 | `fetch_dc_concept_ma5.py` | \(\Phi_{\mathrm{dc}}\) |
| 沿 MA5 多头扫描（右侧交易） | `fetch_a_low_ma5.py` | \(\Phi_{\mathrm{MA5}}\) |
| 量价六组合分类 | `fetch_vp_six_combo.py` | \(\kappa,\ W_k\) |
| 形态建仓信号（突破回踩 / 下跌放量反转） | `fetch_pattern_entry.py` | \(\Pi_4,\ \Pi_6\) |
| 按成长因子排序（资产安全、现金流质量） | `factor_growthT_indicator.py` | \(G\) |
| 市场温度计 - 每日仓位报告 | `market_temperature_model.py` | \(S,\ \pi\) |
| 回测对比 · 底部放量上涨+上涨缩量整理 vs 原4+6（仅多头年化） | `run_vp_combo_23_long_compare.py` | \(H_0\) |
| 市场中性 · 形态/PE/Q/MUD 个股多空 | `market_neutral/run.py` | \(Q,\ M^+,\ M^-,\ B\) |

日频有两条互不传递名单的扫描，形态建仓只接六组合：

\[
\begin{aligned}
\mathcal{R}_t &= \Phi_{\mathrm{MA5}}(\mathcal{P}_t) \\
\kappa_t &= \kappa(\mathcal{S}_t),\quad
\mathcal{S}_t=\begin{cases}
\text{粘贴或自定义列表} & \text{非空}\\
\mathcal{P}_t & \text{否则}
\end{cases} \\
W_{k,t} &\leftarrow \kappa_t \to \Pi_t
\end{aligned}
\]

\(\mathcal{P}_t\) 是 `stocks_pool.txt`。\(\Phi_{\mathrm{MA5}}\) 只写自己的扫描表，\(\mathcal{R}_t\) 不进入 \(\kappa\)。概念漏斗仍可把清洗后的成分写入六组合自定义列表，那是另一条输入，不是 MA5 链。

截面排序 \(Q,M^+,M^-,B,G\) 不改池成员。\(\pi\) 是总仓，\(f\) 是单票上限。\(H_0\) 是待证假设。

## 8. 假设 \(H_0\)

步骤：回测对比 · 底部放量上涨 + 上涨缩量整理 vs 原 4+6（仅多头年化）。

\[
H_0:\ \mathrm{Ann}\big(\mathrm{Long}(W_2\cup W_3)\big)\le \mathrm{Ann}\big(\mathrm{Long}(W_4\cup W_6)\big)
\]

| 项 | 当前取值 | 类型 | 代码 |
|---|---|---|---|
| 比较对象 | 仅多头腿 `*_L` 的年化 | 假设 | `run_vp_combo_23_long_compare.py` 文件头第 3–16 行 |
| 变体 | \(A\) 形态，\(B\) 相对 PE，\(Q\)，\(M^+\)，\(M^-\) | 假设 | `workflow_runner.yaml` 中该步 `args`：`--variants A,B,Q,M+,M-` |
| 分位 | \(q=0.10\) | 假设 | `--quantile 0.10` |
| 调仓 | 周频；\(Q\) 月调 | 假设 | `--rebalance weekly`，`--q-rebalance monthly` |
| 当前运行 | `--skip-backtest`：写 \(W_2,W_3\) 与排名，不判决 \(H_0\) | 运行开关 | 同一步 `args`。排名表不是对 \(H_0\) 的结论 |

中性多空（市场中性 · 形态/PE/Q/MUD 个股多空）是同一截面的另一个读数：多头最高 \(q\)、空头最低 \(q\)。它检验因子方向，不改 combo 6 的入池条件。

2. 门闩：记录改前改后的成员，再看其后收益。下跌 combo 6 的入池条件是最终 `combo_id=6`，不要把 `match_exact` 或共振分加成新门闩。
3. 分数：池成员应与改前相同，只比较次序或 IC。
4. 假设：门闩公式保持不动，否则分不清是池子变了还是命题变了。
5. 改完后若行号或常数变了，回写本表对应行。
