# 量价六组合：洗盘—抛压衰减—再次拉升事件识别器

我建议把这套模型设计为你现有量化系统中的一个独立事件识别模块，而不是新增一个孤立的买入指标。

你的六组合已经覆盖了关键的市场行为：底部缩量、底部放量上涨、上涨缩量整理、上涨放量突破、高位放量滞涨、下跌放量。它们可以进一步组织成一个事件链：

底部建立观察池 → 趋势启动 → 上涨缩量整理 → 抛压衰减验证 → 放量突破 → 持有或退出。

与此同时，高位放量滞涨和下跌放量负责识别风险，防止模型把所有缩量回调都误判为洗盘。

核心设计原则：保留你的六种形态定义，在其上增加位置判定、事件顺序、确认规则和失效条件。 我们不预设主力意图，而是验证哪些量价序列在未来10个交易日具有更好的收益与风险特征。

## 一、六组合的量化定义

以下参数是第一版待检验的基准值，不是经过历史数据证明的最优阈值。建议先用它们建立可复现的回测，再通过训练集和样本外验证决定是否调整。

### 1. 统一基础变量

| 变量            | 定义                 | 用途          |
| ------------- | ------------------ | ----------- |
| \\(R_t\\)     | 当日收盘收益率            | 判断价格方向      |
| \\(VR_t\\)    | 当日成交量 / 过去20日平均成交量 | 衡量量能放大或收缩   |
| \\(MA20_t\\)  | 20日收盘均线            | 判断短期趋势      |
| \\(HH60_t\\)  | 前60个交易日最高价，不含当日    | 识别突破        |
| \\(LL60_t\\)  | 前60个交易日最低价         | 辅助判断底部区域    |
| \\(ATR20_t\\) | 20日真实波幅均值          | 衡量正常波动与止损距离 |
| \\(DD_t\\)    | 收盘价相对过去60日最高收盘价的回撤 | 判断所处价格位置    |

成交量必须使用截至当日已经可知的数据。若使用复权价格，成交量和成交额数据也要保持时间对齐；停牌日不能被当成普通缩量日。

### 2. 保留六组合的定义，并转化为程序条件

## 01

底部缩量

- 位置：收盘价处于过去60日价格区间的底部20%，作为第一版定义。
- 量能：\\(VR_t \le 0.7\\)。
- 价格：不强制要求上涨，保留你原有的缩量定义。

作用：进入观察池。它只能说明交投清淡，不能单独证明卖压耗尽。

## 02

底部放量上涨

- 位置：底部区域。
- 价格：\\(R_t>0\\)。
- 量能：\\(VR_t\ge1.5\\)。

作用：候选启动信号。更强的版本要求收盘价靠近当日高点，并且突破近期局部高点。

## 03

上涨缩量整理

- 位置：已经形成上涨趋势。
- 价格：整理期间不出现显著破位。
- 量能：\\(VR_t\le0.8\\)。

作用：洗盘候选阶段。建议用连续3—8个交易日观察，不能把单日缩量直接认定为洗盘。

## 04

上涨放量突破

- 位置：上涨趋势中。
- 价格：突破前期整理区高点，或者至少上涨。
- 量能：\\(VR_t\ge1.3\\)。

作用：确认信号。为降低假突破，优先要求收盘价高于前5—10日整理区高点，而不是只看盘中最高价。

## 05

高位放量滞涨

- 位置：价格处于过去60日区间顶部20%，或距近期高点较近。
- 量能：\\(VR_t\ge1.5\\)。
- 价格：涨幅不超过0.5%，或收盘未上涨。

作用：风险标记。应观察是否连续出现、是否伴随长上影线，以及后续是否跌破整理区。

## 06

下跌放量

- 位置：下跌途中，或价格处于下降趋势。
- 价格：\\(R_t<0\\)。
- 量能：\\(VR_t\ge1.5\\)。

作用：风险标记。如果出现在缩量整理阶段并伴随支撑破位，取消洗盘假设；若发生在后续企稳反转前，则先观察，不提前认定为底部。

这里有两个容易被忽略的细节。

第一，底部、高位都是相对位置，不是固定股价。第二，形态允许重叠，例如一只股票可能同时处于高位、放量且滞涨。程序应保留所有命中的标签，再由状态机决定其优先级，不能简单地强制每一天只能属于一种形态。

## 二、建立事件状态机

六组合需要从“六个独立标签”变成“有先后顺序的市场事件”。我建议设置以下七个状态。

S0：未触发

初始状态

没有满足底部观察条件，或前一个事件已经结束。

S1：底部观察

形态 01

底部位置 + 缩量。进入候选池，等待放量上涨，不买入。

S2：上涨启动

形态 02

底部放量上涨，确认出现初始需求。若没有后续趋势延续，只记录为失败启动。

S3：缩量整理

形态 03

已出现上涨，随后进入3—8日整理。记录整理区高点、低点和成交量变化。

S4：抛压衰减候选

重点研究

缩量、支撑未破、回撤受控。只是候选状态，不代表已确认洗盘完成。

S5：突破确认

形态 04

收盘突破整理区高点，并满足放量条件。记录确认日，下一交易日才按回测规则执行买入。

S6：持仓 / 退出

最多10日

持仓期间监控止损、失效条件、高位放量滞涨、下跌放量及持有期到期。

### 状态转换规则

| 当前状态  | 触发条件         | 下一状态    | 处理         |
| ----- | ------------ | ------- | ---------- |
| S0    | 形态01         | S1      | 加入观察池      |
| S1    | 形态02         | S2      | 记录启动日与启动低点 |
| S2    | 上涨延续后出现形态03  | S3      | 记录整理区      |
| S3    | 缩量且支撑保持      | S4      | 记录抛压衰减候选   |
| S4    | 形态04满足突破条件   | S5      | 产生交易信号     |
| S1—S4 | 形态06并且关键支撑破位 | S0      | 事件失败       |
| S3—S5 | 形态05并且出现结构破坏 | S0或风险状态 | 取消买入候选     |
| S5    | 下一交易日可成交     | S6      | 建立持仓       |
| S6    | 止损、失效或持有期到期  | S0      | 退出或等待新事件   |

这里的状态机不要求每只股票必须先经历 S1 才能交易。如果某只股票从上涨中途开始观察，可以把它标记为“缺少底部阶段的独立事件”，单独统计，不与完整事件链混为一谈。

## 三、怎样判断抛压正在衰减？

这是整个模型最关键的环节。单纯缩量可能代表抛压减轻，也可能代表买盘消失，所以我建议至少使用三个条件共同判断。

### 抛压衰减评分

令：

- \\(V_f\\)：整理期平均成交量 / 启动期平均成交量。
- \\(D\\)：整理期最大回撤 / 启动阶段涨幅。
- \\(L\\)：整理期最低价相对启动前关键低点的位置。
- \\(Q\\)：下跌日成交量是否逐步下降。

可以构建一个简单的初始评分：

\\[ S\_{\text{fade}} = 0.35S_V+0.25S_D+0.25S_L+0.15S_Q \\]

各个子评分统一归一化到 0—1。

| 子评分       | 满分的初始条件              | 解释         |
| --------- | -------------------- | ---------- |
| \\(S_V\\) | 整理期均量不超过启动期均量的70%    | 交投明显收缩     |
| \\(S_D\\) | 整理回撤不超过启动涨幅的50%      | 没有大幅吞噬启动涨幅 |
| \\(S_L\\) | 未跌破启动前关键低点或明确支撑      | 结构仍然有效     |
| \\(S_Q\\) | 下跌日成交量总体下降，未出现显著放量破位 | 卖压没有持续恶化   |

实际实现时，子评分应当连续变化，而不是只有满足条件才得1分。例如成交量比从0.7变成0.9时，评分应逐渐降低，而不是突然从满分降至零。

第一版入选规则： \\(S\_{\text{fade}}\ge0.7\\)，且关键支撑未破，才进入 S4。

权重和阈值均为研究起点，后续要用历史样本优化并做样本外验证。不要因为某组权重在训练期收益最高就直接采用。

还有一个重要限制：日线成交量无法直接识别哪些交易来自套牢盘卖出。这个评分衡量的是可观察的抛压代理变量，而不是已经释放了多少真实套牢筹码。

## 四、突破确认、信号时间与买入规则

为了让回测结果可信，必须严格区分“形态出现”“事件确认”和“实际成交”三个时间点。

### 1. 突破确认条件

在 S4 状态中，先固定整理区：

- 整理区高点 \\(H_c\\)：整理期内的最高价。
- 整理区低点 \\(L_c\\)：整理期内的最低价。
- 突破日成交量比 \\(VR_t\\)：当日成交量 / 前20个交易日平均成交量。

第一版确认规则：

\\[ \begin{aligned} C_t &> H_c + 0.2ATR20_t\\\ VR_t &\ge 1.3\\\ C_t &> MA20_t \end{aligned} \\]

其中 \\(C_t\\) 为当日收盘价。

这是一种偏严格的突破定义，目的是减少盘中假突破。你原有的“上涨放量突破”仍然保留，但模型的交易版本额外要求收盘有效突破。若你想单独研究“仅上涨但没有突破”的版本，应将它作为另一组独立实验，而不是悄悄混进同一策略。

### 2. 信号确认时间

T 日

收盘后确认

根据当天完整日线数据判断是否突破。只有收盘后才能确定当日收盘价、成交量和形态标签。

T+1 日

执行买入

以次日开盘价作为基准成交价，加入滑点和交易费用。若停牌、涨停无法成交，或成交条件不满足，则记录为未成交，不能假定一定买到。

T+1 至 T+10

持仓与退出

监控止损、结构失效、风险形态和持有期。A股需要考虑 T+1 交易限制，买入当天不能按普通现货交易规则立即卖出。

建议同时记录两套收益：

- 信号收益： 突破确认日收盘价之后的理论收益，用于研究形态。
- 可执行收益： 次日实际可成交价格之后的收益，用于评估真实交易价值。

如果信号收益很好、可执行收益明显变差，可能意味着信号确认太晚、隔夜跳空较大，或策略承受了较高的交易成本。

## 五、止损与事件失效条件

不要把“持有10天”当成唯一的退出规则。模型应同时设置价格止损、结构失效和时间退出。

| 退出类型  | 第一版规则                         | 目的           |
| ----- | ----------------------------- | ------------ |
| 结构止损  | 收盘跌破整理区低点 \\(L_c\\)，并超过预设波动缓冲 | 原有整理结构失效     |
| ATR止损 | 买入价下方 \\(1.5ATR20\\)          | 控制单笔风险       |
| 放量破位  | 形态06出现，且收盘跌破关键支撑              | 防止将趋势破坏误认成洗盘 |
| 高位风险  | 形态05出现，随后跌破整理区或短期支撑           | 避免高位滞涨后的下跌   |
| 时间退出  | 持仓达到10个交易日                    | 保持与研究目标一致    |
| 突破失败  | 突破后在预设观察期内重新跌回整理区             | 退出失败突破交易     |

以上止损条件需要明确优先级。我的建议是：

1. 价格止损优先于普通持有期退出。
2. 结构失效优先于趋势延续预期。
3. 高位放量滞涨先作为警报；只有与破位等条件结合时，才触发严格退出。
4. 任何退出信号都必须按真实可成交时间处理，不能用当日收盘后才知道的信号假设在同一收盘价成交。

对于 ATR 止损，如果日线最低价已经跳过止损价，应按回测模型设定的可成交价格处理，不能一律按止损价成交。真实市场存在跳空、涨跌停、流动性不足等情况。

另外，结构止损和 ATR 止损可能给出不同的止损距离。建议在回测报告里同时记录两者，先比较哪一种风险控制方式更有效，再确定最终规则。

## 六、样本外回测：证明它不是普通上涨策略的重复

这一步对你现有的量化系统尤其重要：我们不只是看策略赚钱没有，还要证明“洗盘—抛压衰减—突破”这个事件链，是否比单纯放量突破提供额外的信息。

### 1. 设计四组对照实验

| 实验组       | 选股条件                   | 要回答的问题       |
| --------- | ---------------------- | ------------ |
| A：完整事件链   | 02 → 03 → 04，且满足抛压衰减评分 | 完整事件链是否有效？   |
| B：普通放量突破  | 仅满足形态04                | 事件链是否优于普通突破？ |
| C：缩量整理后突破 | 03 → 04，不要求评分          | 评分是否提供额外信息？  |
| D：底部启动后突破 | 02 → 04，不要求缩量整理        | 洗盘阶段是否有增量价值？ |

四组必须使用相同股票池、交易时段、成交规则和成本模型。每组都以相同的10日持有周期为主测试，另外再观察3日、5日和20日收益作为辅助结果。

如果 A 组收益高于 B 组，但交易次数大幅减少，也不能只比较累计收益。必须同时观察每笔交易收益、风险、样本量和资金利用率。

### 2. 时间切分与滚动验证

建议使用按时间前后切分的数据，而不是随机打乱交易样本。

训练集

约60%

验证集

约20%

测试集

约20%

比例是初始建议。应按日期切分，并在测试期开始前锁定全部规则；滚动验证时，每次只使用当时已经可知的历史数据。

推荐流程：

1. 训练集：确定合理的阈值范围、评分函数和风险规则。
2. 验证集：选择参数，检查结果对参数变化是否敏感。
3. 测试集：冻结策略后只评估一次，不根据结果继续修改。
4. 滚动样本外：逐段向前推进，重复训练、验证和测试。
5. 做事件隔离：同一只股票的连续突破信号可能属于同一个事件，不能当作大量相互独立的成功案例。

还要避免幸存者偏差：历史股票池需要包含退市、长期停牌及后来表现不佳的股票，而不是只使用今天仍然表现良好的成分股。

## 七、交易成本与绩效评估

回测至少需要纳入以下因素：

- 买卖双边佣金、适用的卖出印花税及其他费用。
- 买卖滑点；可根据成交额、流动性和交易规模设置不同假设。
- 涨跌停、停牌、跳空和无法成交的情况。
- 信号发生时的实际可交易股票池，以及真实的成交顺序。
- 如果多个信号同时出现，必须有明确的仓位分配和资金不足处理规则。

建议至少输出以下指标：

| 指标               | 作用              |
| ---------------- | --------------- |
| 扣费后平均单笔收益        | 判断单次交易的期望收益     |
| 胜率与盈亏比           | 观察收益结构          |
| 最大回撤             | 评估资金承受的损失       |
| Sharpe / Sortino | 评估风险调整后收益       |
| Profit Factor    | 总盈利与总亏损的比例      |
| MAE / MFE        | 观察入场后的最大不利与有利变动 |
| 10日超额收益          | 判断是否跑赢基准        |
| 事件数量与覆盖率         | 防止结果由少量极端交易决定   |

对每笔交易，还应该记录信号日期、状态转换路径、入场价、退出原因、毛收益、费用、净收益以及对应的市场状态。这样才能分析：究竟是底部启动有效，还是缩量整理有效，或者只是市场整体上涨带来了收益。

## 八、如何判断模型是否值得加入你的系统？

我建议预先设定三个通过条件。

第一，事件识别有效。 完整事件链在样本外的10日净收益、超额收益或风险调整后收益，相比普通放量突破具有稳定的改善。

第二，风险控制有效。 形态05和06能够识别一部分失败事件，并改善最大回撤或 MAE，而不是只增加交易过滤条件。

第三，结果具有稳健性。 在不同年份、不同市场状态、不同流动性股票中，效果并非完全依赖单一行情；合理改变阈值后，收益也不会立即消失。

如果结果不满足这些条件，就应该把它保留为观察指标，而不是直接作为买入因子。

## 九、最终的模块设计

输入层：六组合 + 日线行情

开高低收、成交量、成交额、均线、ATR、市场及行业基准

事件识别层

位置判定 → 六组合标签 → 状态机 → 抛压衰减评分

交易决策层

突破确认 → 下一交易日成交 → 仓位分配 → 止损与10日退出

评估层

样本外回测 → 成本后收益 → 失败事件归因 → 与现有 Alpha 因子比较

我的最终建议是：先把这套模型作为一个独立的“事件 Alpha”进行检验，不要一开始就将它和你现有的选股因子混合加权。 先证明它在普通放量突破之外提供了增量信息，再决定是否纳入综合评分或动态仓位系统。

如果要真正落地，最有价值的下一步是把上述规则转成一份明确的程序规格：输入字段、每日状态转移、事件日志、交易执行、回测报告和样本外验证全部统一起来。这样你的六组合才会从图形分类工具变成能够接受数据检验的量化策略。
