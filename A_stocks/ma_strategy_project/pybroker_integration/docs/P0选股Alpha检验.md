# P0 选股 Alpha 检验

脚本：`p0_alpha_report.py`。

只出报告，不改线上入池规则，不做均值—方差、半凯利、收益排序和温度仓位。

四张表：相对沪深300的超额和 \(\alpha+\beta R_m\)；\(W_2\) 到 \(W_6\) 在信号日后 1、3、5、10、20 个交易日的收益；\(M^+\)、\(Q\)、\(G\) 的 IC 及衰减；按温度总分分组的条件日收益。\(G\) 是营收同比与净利润同比。状态不做连续分数的 IC。标签 A/B/C/D 只作诊断。

运行：

```text
python p0_alpha_report.py
```

产物在 `output/p0_alpha/report.md`。
