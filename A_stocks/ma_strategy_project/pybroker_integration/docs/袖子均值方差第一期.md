# 袖子均值—方差第一期

脚本：`sleeve_mv_experiment.py`。

四条袖子的日收益：

- \(W_4\)、\(W_6\)：初始 θ 的 Phase1 分类，滚动 6 个交易日，同票只留最新 combo。袖子内部等权。
- \(M^+\)、\(Q\)：在当日 \(W_4 \cup W_6\) 里各取前 2 名，内部等权。\(W_2\)、\(W_3\) 不进入。

持仓在当日收盘确定，收益记到下一交易日。样本外比较三种加权：等权、按估计窗里的过去收益（负收益记 0，全负则退回等权）、收缩后的均值—方差。风险厌恶 λ=1，协方差向平均方差的对角收缩 50%，只做多且权重和为 1。λ 与收缩强度不在测试段里挑选。

估计窗 126 个交易日，测试窗 63 个交易日。最后约 20% 交易日只评价一次。温度 π(S) 只乘在总仓位上，不再改 λ。单票再与共用半凯利和 20% 上限取较小值。

名单少于 8 只，或均值—方差没有在滚动测试和最后一段同时胜过等权时，组合层保持等权，均值—方差只留在报告里。

运行：

```text
python sleeve_mv_experiment.py
```

产物在 `output/sleeve_mv/report.md`。脚本不修改 `VP_SIX_CONFIG` 和 `config/workflow_runner.yaml`。
