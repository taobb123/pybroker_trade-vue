# 数据目录

本目录管理项目所需的所有数据，按照数据处理的阶段分为三个子目录。

## 目录结构

### raw/ - 原始数据
存放原始的、不可更改的初始数据转储。
- 从数据源直接下载的原始数据
- 未经任何处理的原始CSV、JSON等文件
- **注意**: 这些数据不应被修改

### interim/ - 中间数据
存放中间处理过程生成的数据。
- 数据清洗后的中间结果
- 特征工程过程中的中间数据
- 数据转换的中间产物

### processed/ - 最终数据
存放可直接用于模型训练或回测的最终、规范化数据集。
- 完全处理好的、标准化的数据
- 可以直接用于策略回测的数据
- 特征工程完成后的最终数据集

## 数据管理原则

1. **原始数据保护**: raw/ 目录中的数据不应被修改
2. **版本控制**: 处理后的数据应记录处理版本和日期
3. **数据文档**: 每个数据集应有对应的说明文档
4. **数据清理**: 定期清理过期的中间数据

## 文件命名规范

建议使用以下命名规范：
- `{symbol}_{start_date}_{end_date}_{version}.csv`
- `{dataset_name}_{processing_date}_{version}.parquet`

## .gitignore 建议

建议在 `.gitignore` 中忽略大型数据文件：
```
data/raw/*.csv
data/raw/*.parquet
data/interim/*
data/processed/*
!data/processed/.gitkeep
```
