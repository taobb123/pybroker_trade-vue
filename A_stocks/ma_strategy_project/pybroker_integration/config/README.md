# 配置文件目录

本目录存放所有的配置文件，包括：

## 配置文件类型

- **数据库配置**: 数据库连接信息、连接池配置等
- **模型参数**: 机器学习模型、策略参数等
- **系统设置**: 日志配置、缓存配置、API密钥等
- **环境配置**: 开发环境、测试环境、生产环境的配置分离

## 配置管理原则

1. **环境分离**: 生产环境和开发环境的配置应分离管理
2. **敏感信息**: 敏感信息（如API密钥、密码）应使用环境变量或密钥管理服务
3. **版本控制**: 配置文件应纳入版本控制，但敏感信息应使用占位符

## 示例文件结构

```
config/
├── __init__.py
├── dev_config.py          # 开发环境配置
├── prod_config.py         # 生产环境配置
├── test_config.py         # 测试环境配置
├── db_config.py           # 数据库配置
├── model_config.py        # 模型参数配置
└── settings.py            # 系统设置
```
